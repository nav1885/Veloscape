One new row in Voice & Audio: "Generate text summaries for non-coached rides". Default ON. Off saves LLM cost. Coached rides always get the rich narrative regardless.

Key visual decisions to validate:
  • Gold 🎙 Coached pill sits beside the existing 4-state SyncStateBadge — orthogonal axes, not a 5th state.
  • Inline ▶ button on every Home row plays audio without navigating away. Tap the row body to navigate.
  • "Play debrief" on PostRideSummary is a primary CTA (gold pill, 56px tall) — audio is first-class.
  • SummaryText shimmer is the only loading affordance — the rest of the screen renders normally.
  • LLM is invisible: no "AI" framing, no model name, no robot icon. The text is the text.
  • MetricsBlock degrades gracefully — "Building your baseline · N/5" when there's less than 5 rides of history.
  • Sparklines are micro: 60×20px, last 5 efforts, gold line, latest dot, dashed PR baseline.
